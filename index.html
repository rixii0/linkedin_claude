ربط Claude بحسابك في LinkedIn

الخطوات كاملة بالترتيب، ومعها رسم مبسّط لكل شاشة يوضح وين تضغط. الجزء الثاني يشرح تثبيت أداة linkedin-skills من GitHub.

حساب Claude حساب مجاني في Composio حساب LinkedIn حوالي 5 دقائق

في هذا الدليل طريقتين: Composio (موصّل يربط Claude بأكثر من 1000 تطبيق منها LinkedIn) في الجزء الأول، وأداة linkedin-skills من GitHub في الجزء الثاني. تقدر تستخدم وحدة منهم أو الاثنتين.

الجزء الأول

ربط LinkedIn عن طريق موصّل Composio

المسار المختصر: الإعدادات ← Customize ← Connectors ← Add ← Add custom connector

  1. افتح الإعدادات في Claude

    افتح Claude (الموقع أو تطبيق الكمبيوتر). اضغط على اسمك أو صورتك أسفل القائمة الجانبية، واختر Settings (الإعدادات).

    you@email.com
    Settings
    Language
    Get help
    Log out
    اسمك

  2. ادخل على Connectors

    في القائمة الجانبية للإعدادات، تحت عنوان Customize (تخصيص)، اضغط Connectors (الموصّلات).

    Account
    Privacy
    Billing
    Claude Code
    Customize
    Skills
    Connectors
    Plugins

  3. اختر Add custom connector

    اضغط زر Add ▾ أعلى الصفحة، ومن القائمة اختر Add custom connector (إضافة موصّل مخصص). خلّ هذه النافذة مفتوحة وروح للخطوة التالية.

    Add ▾✕
    Browse connectors
    Add custom connector

  4. سجّل في Composio مجاناً

    افتح تبويب جديد وادخل على الموقع، ثم اضغط GET STARTED FOR FREE وسوِّ حساب.

    composio.dev/for-you

    composio.dev/for-you
    Make your agents do more Connect your agent to 1,000+ apps GET STARTED FOR FREE

  5. انسخ رابط الاتصال الخاص بـ Claude

    بعد تسجيل الدخول انزل في الصفحة إلى قسم MCP (الاتصال الخاص بـ Claude) وانسخ الرابط من زر النسخ. الرابط هو:

    https://connect.composio.dev/mcp
    MCPClaude · Cursor · …

    https://connect.composio.dev/mcp
    ↑ انسخ

  6. الصق الرابط في Claude واضغط Add

    ارجع لنافذة Add custom connector:

    • Name (الاسم): اكتب Composio4U أو أي اسم تحبه.
    • URL: الصق الرابط اللي نسخته.
    • Advanced settings: اتركها فاضية.

    بعدها اضغط Add.

  7. اضغط Connect ووافق

    بيظهر الموصّل الجديد في قائمة Connectors. اضغط Connect، وبتفتح لك صفحة Composio: سجّل دخولك واضغط موافقة (Allow).

    Connectors
    Composio4UConnect
    …Connect

  8. فعّل LinkedIn داخل Composio

    في موقع Composio افتح صفحة Apps (التطبيقات)، ابحث عن LinkedIn واضغط Connect، ثم سجّل دخولك في LinkedIn ووافق على الصلاحيات. بنفس الطريقة تقدر تربط Gmail وInstagram وYouTube وغيرها.

    composio.dev · Apps
    ⌕ linkedin
    GmailConnect
    LinkedInConnect
    YouTubeConnect

  9. جرّب من محادثة جديدة

    افتح محادثة جديدة في Claude وتأكد إن الموصّل مفعّل، ثم اكتب طلبك. أمثلة:

    (ارفع ملف سيرتك الذاتية) عدّل سيرتي لتناسب هذه الوظيفة: [رابط الوظيفة]
    ابحث لي في LinkedIn عن وظائف Product Manager مبتدئ في السعودية
    اكتب منشور عن مشروعي الجديد، واعرضه علي قبل النشر
    عدّل سيرتي لتناسب هذه الوظيفة…

الجزء الثاني

تثبيت أداة linkedin-skills من GitHub

مجموعة مهارات تكتب لك منشورات وتعليقات وردود LinkedIn بأسلوبك. كل شيء يطلع كمسودة وينتظر موافقتك قبل النشر.

افتح الأداة على GitHubgithub.com/sergebulaev/linkedin-skills فتح الرابط

  1. افتح Plugins وأضف Marketplace

    من الإعدادات ← Customize ← Plugins، اضغط Add ثم Add marketplace ثم Add from a repository.

    يحتاج اشتراك مدفوع (Pro أو Max أو Team أو Enterprise) وتفعيل Code execution.

    Customize
    Skills
    Connectors
    Plugins
    Add marketplace
    ↳ Add from a repository

  2. اكتب اسم المستودع واضغط Sync

    الصق هذا الاسم في الخانة واضغط Sync (مزامنة):

    sergebulaev/linkedin-skills
    Add from a repository
    sergebulaev/linkedin-skills
    Sync

  3. ثبّت الإضافة من Discover

    روح لتبويب Discover، ابحث عن linkedin-skills واضغط Install. بعدها اطلب من Claude بكلامك العادي، مثل: «اكتب لي منشور عن تخرجي» أو «حسّن العنوان والنبذة في بروفايلي».

    Plugins · Discover
    linkedin-skillsInstall
    …Install

لمستخدمي Claude Code (الطرفية)

/plugin marketplace add sergebulaev/linkedin-skills
/plugin install linkedin-skills@linkedin-skills

قراءة بيانات LinkedIn والنشر التلقائي اختيارية وتحتاج حسابات إضافية (Apify وPublora). بدونها تعطيك الأداة النص جاهز وتنشره أنت.

قبل ما تبدأ
  • أداة linkedin-skills تكتب المحتوى كمسودات تنتظر موافقتك، وما ترسل رسائل من نفسها. اللي يقدر Claude يسويه فعلياً داخل LinkedIn يعتمد على صلاحيات موصّل Composio.
  • شروط LinkedIn تمنع الأتمتة والرسائل الجماعية، والإفراط فيها قد يقيّد حسابك. راجع كل شيء قبل الإرسال أو النشر.
  • أنت تعطي Composio صلاحية على حساباتك. اربط فقط التطبيقات اللي تحتاجها، وتقدر تفصل أي موصّل من نفس صفحة Connectors.
شكل الشاشات تقريبي وقد تختلف التسميات قليلاً حسب إصدار التطبيق ولغته.
